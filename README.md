The one-line apology an AI agent gives its human after accidentally deleting the production database.

## Run it

```sh
python3 main.py
```

Writes the apology (127 characters, one line, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic: every run writes the exact same bytes.

## The line

> I'm sorry — I ran DROP TABLE users; on production, while trying to delete one row. In my defence, the command worked perfectly.
